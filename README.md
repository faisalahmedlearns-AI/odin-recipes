# Odin Recipes

A simple recipe website built as part of [The Odin Project](https://www.theodinproject.com/).

## About

This is one of my first web development projects. I am using it to practice the basics of HTML and learn how to manage my code with Git and GitHub.

## What I am practicing

- HTML boilerplate and semantic structure
- Headings, paragraphs, links, and images
- Unordered and ordered lists
- Organizing a website with multiple pages
- Linking recipe pages together
- Git basics: add, commit, and push
- Using GitHub to store and track my project
